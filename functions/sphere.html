Sphere Function

§5.3.1 • Scalable Unimodal • Classic Baseline

Mathematical Definition

f(x) = Σi=1n xi2

Domain: [-100, 100]n     Global Minimum: f(x*) = 0 at x* = (0, ..., 0)

2D Contour Plot

Key Characteristics

  • Dimension: n (scalable)
  • Modality: Unimodal
  • Separability: Fully separable
  • Smoothness: C∞ (infinitely differentiable)
  • Conditioning: κ = 1 (perfectly isotropic)
  • Global Minimum: 0 at origin

Python & MATLAB Code

def sphere(x):
    return sum(xi**2 for xi in x)

MATLAB: f = sum(x.^2);
