Sphere Function

§5.3.1 • Scalable Unimodal

Mathematical Definition

f(x) = Σ xᵢ² for i = 1 to n

Domain: [-100, 100]ⁿ

Key Characteristics

  • Dimension: n (scalable)
  • Domain: [-100, 100]ⁿ
  • Global Minimum: f(x*) = 0 at x* = (0, ..., 0)
  • Modality: Unimodal
  • Separability: Separable
  • Smoothness: C∞ (infinitely differentiable)
  • Conditioning: κ = 1 (isotropic)

Python & MATLAB Code

def sphere(x):
    return sum(xi**2 for xi in x)

MATLAB: `f = sum(x.^2);`
